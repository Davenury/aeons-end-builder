# Aeon's End Builder

The builder allows you to create their own cards for Aeon's End. There are four main categories:
* Mage - where you create the mage card
* Supply - where you create Gems, Relics, and Spells
* Nemesis - where you create Nemesis card
* Nemesis Cards - where you create cards for Nemesis deck.

## Special characters
In every text field you can use special words that will later be enriched into symbols:
* ${aether} - it will be changed to aether icon
* ${aether-white} - it will be changed to white aether icon (use on dark surfaces)

## Advanced settings
Each form contains a toggle to use advanced settings. Those include manipulation of placement of each element. The placement should be more-or-less ok on your computer as well, yet those settings are there for the purpose of tweaking positions, when needed. You can eyeball and more-or-less guess the numbers in the fields to set the elements where there should be.
